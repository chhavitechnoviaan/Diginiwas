# DigiNiwas notification setup
Existing FCM registration and in-app notifications are retained. Admin role is now supported by the device registration endpoint; web/mobile clients must register their FCM token themselves. No frontend SDK changes are included.

Configure SMTP in the existing local .env (see .env.example). Admin notifications created through notifyUser are queued to diginiwas@gmail.com, one email per newly created admin notification (multiple admin accounts may therefore receive duplicate copies at the shared mailbox). Partner rejection emails embed the existing project logo. Promotion notifications are queued after the refund transaction commits. Account rejection requires remarks and admin authorization.

Automatic WhatsApp delivery has been removed. All external notification emails include a green Contact Us on WhatsApp button and a plain-text fallback link to https://api.whatsapp.com/send/?phone=917988537478&text&type=phone_number&app_absent=0. The recipient chooses whether to send a message. No Meta credentials or templates are needed. Remove obsolete WHATSAPP_* settings from your local .env. The worker processes email jobs only; historical WhatsApp jobs are retained but never picked up by this worker. Stop all old backend workers before deploying this version.

Worker polls MongoDB NotificationDelivery every 15 seconds; failed attempts retry up to five times. Sent means provider accepted the request, not confirmed delivery. A process crash during Sending leaves the job in Sending; inspect provider logs before manually requeueing to avoid duplicate delivery. Queue insertion is best effort after notification creation, not transactional with business operations. Existing historical notifications are not backfilled. Restrict access to delivery collection (contains recipient details).

Test: run npm install, configure existing MongoDB/Firebase/SMTP credentials, npm run dev. Register FCM token using authenticated POST /api/v1/notifications/devices with {"token":"...","platform":"android"} (web/ios also supported). Reject a pending account or promotion with {"remarks":"Please update the required details"} as admin. Verify Notification and NotificationDelivery collections, credit refund for promotion, and email/push receipt. Open the email button and verify that it opens the support chat for +91 7988537478. Verify no new WhatsApp delivery jobs are created. No live provider testing performed.
